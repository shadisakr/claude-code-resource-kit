# Expense Tracker (practice project)

A tiny command-line app for logging expenses. It works, mostly. It has a few bugs and no tests on purpose, so you can practise fixing and testing with Claude Code.

Needs Python 3.10 or later. No other packages required (pytest is optional, for the testing exercises).

```bash
python -m expense_tracker add 12.50 food "Lunch"
python -m expense_tracker list
python -m expense_tracker summary 2026-11
```

Data is saved to `expenses.json` in the folder you run it from.

Start with `EXERCISES.md`.
