# Claude Code Resource Kit

Provided by Sinai Observer dot AI (sinaiobserver.ai) for the Claude Code full course.

Everything in this folder is plain text. Open it in any editor, copy what you need into your own projects, and change it to fit how you work.

## What's inside

| Folder | What it's for | Course module |
| --- | --- | --- |
| `01-setup/` | Install Claude Code on any OS and run your first session | Setup |
| `02-claude-md/` | A `CLAUDE.md` template and a filled-in example | Project memory |
| `03-prompts/` | A prompt library for planning, debugging, refactoring, tests and reviews | Prompting |
| `04-skills/` | Four ready-to-use skills you can drop into `.claude/skills/` | Skills |
| `05-subagents/` | Three custom subagents (reviewer, debugger, test writer) | Subagents |
| `06-hooks-and-settings/` | A starter `settings.json` with permission rules and hooks | Hooks and permissions |
| `07-mcp/` | An example `.mcp.json` and notes on connecting tools | MCP |
| `starter-project/` | A small Python app with planted bugs and no tests, for practice | Hands-on exercises |
| `cheat-sheet.md` | Commands, shortcuts and flags on one page | Reference |

## How to use it with the course

1. Start with `01-setup/install-and-first-run.md`.
2. Open `starter-project/` in your terminal and follow `starter-project/EXERCISES.md` as you watch each module.
3. When a module covers skills, subagents, hooks or MCP, copy the matching files into the starter project's `.claude/` folder and try them.

## A note on accuracy

Claude Code changes quickly. Everything here was checked against the official docs in November 2026. If a command behaves differently for you, the docs at https://code.claude.com/docs win.
